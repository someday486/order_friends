# 2026-04-02 패치노트

## 신규 기능
- 주문서 내부에 Toss Payments V2 결제위젯을 삽입했습니다.
- 비회원 주문도 공개 주문조회 페이지에서 바로 취소할 수 있게 했습니다.

## 개선 사항
- 주문 페이지 브라우저 탭 제목에 서비스명만 아니라 매장명이 함께 보이도록 바꿨습니다.
- 주문서 연락처는 `000-0000-0000` 형식으로 자동 정리되고, 잘못된 형식은 주문이 막히도록 바꿨습니다.
- 매장에서 픽업 가능 시간을 설정하지 않은 경우 주문서에서 픽업 희망시간 입력 UI를 숨기도록 했습니다.
- 주문하기 이후 다음 단계 전환이 더 빠르게 느껴지도록 이동 흐름을 다듬었습니다.
- 고객용 주문 진입 화면에서 실제로 사용하지 않는 내부 온라인샵 지점 링크가 노출되지 않도록 정리했습니다.
- 문서 체계를 `docs/` 하위 구조 중심으로 재정리하고, 공통 작업 규칙과 문서 레지스트리, 에이전트 지침을 강화했습니다.
- 오늘 날짜 패치노트 자동 생성, 커밋 메시지 기반 초안 추가, 푸시/PR 전 검증 자동화가 동작하도록 작업 흐름을 정리했습니다.

## 버그 수정
- 관리자 주문 상세를 직접 열 때 `__ALL_BRANCHES__` 값 때문에 404가 뜨던 문제를 수정했습니다.
- 깨진 refresh token이 남아 있을 때 로컬 세션이 자동 복구되지 않던 문제를 수정했습니다.
- 고객 레이아웃에서 브라우저 전용 상태를 너무 이르게 읽어 hydration mismatch가 나던 문제를 수정했습니다.
- 완료 주문 환불 시 주문 상태가 올바르게 `REFUNDED`로 이어지지 않던 문제를 수정했습니다.
- 수동 입금확인 후에도 주문관리 목록에서 계속 입금대기로 보이던 문제를 수정했습니다.
- 로그인 주문과 비로그인 주문의 생성/취소 흐름에서 사용자 연결이 어긋나던 케이스를 수정했습니다.
- 주문 연락처 검증 실패 시 영문 에러 대신 소비자 친화적인 한글 안내 문구가 보이도록 바꿨습니다.

## 운영 메모
- 환불 상태 수정은 대상 DB에 `supabase/migrations/20260402094000_fix_refunded_payment_order_status.sql` 마이그레이션이 적용되어야 완전히 반영됩니다.
