# 2026-04-02 Patch Notes

## New Features
- Added embedded Toss Payments V2 widget support to the order checkout flow.
- Added guest order cancellation from the public order tracking page.

## Improvements
- Order page tabs now show the branch name instead of only the service name.
- Order checkout now auto-formats phone numbers into `000-0000-0000` and blocks invalid phone input.
- Pickup requested-time fields are hidden when a branch has not configured pickup time slots.
- Order submission transitions feel faster with prefetched next-step routes.
- Internal online-shop branch links are no longer shown as customer-facing order links.
- Documentation was reorganized into structured `docs/` sections with shared workflow rules, a registry, and stronger agent instructions.

## Bug Fixes
- Fixed admin order detail direct-link 404s caused by `__ALL_BRANCHES__` leaking into the detail request.
- Fixed invalid refresh-token recovery so broken local sessions now self-heal by clearing local auth state and returning users to sign-in.
- Fixed hydration mismatches in customer layout caused by browser-only state being read during the initial render.
- Fixed completed-order refund handling so refunded payments now map to the correct order status.
- Fixed transfer-payment orders so manual deposit confirmation no longer leaves the order-management badge stuck on waiting-for-deposit.
- Fixed guest and logged-in order ownership edge cases around order creation and cancellation.
- Replaced raw English phone-format validation errors with consumer-friendly Korean messaging.
