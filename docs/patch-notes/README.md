# 패치노트

이 폴더에는 사용자나 운영자가 실제로 체감하는 변경 사항을 기록합니다.

## 자동화 동작
- 브랜치를 체크아웃하거나 머지한 뒤 오늘 날짜 패치노트가 없으면 자동으로 생성됩니다.
- 커밋할 때는 커밋 메시지를 기준으로 오늘 날짜 패치노트에 초안이 자동으로 추가됩니다.
- 푸시하거나 PR을 열 때 관련 제품 변경이 있는데 날짜형 패치노트가 없으면 진행이 차단됩니다.
- 기존에 이미 클론해 둔 저장소는 한 번 `npm run hooks:install` 또는 `npm run lint`를 실행해 git hook을 다시 연결해야 자동화가 동작합니다.
- GitHub 브랜치 보호에서 `Docs Governance` 체크를 required로 걸지 않으면, CI 실패가 보여도 직접 푸시된 커밋 자체는 저장소에 들어갈 수 있습니다.

## 파일명 규칙
- `YYYY-MM-DD.md`

## 포함하면 좋은 내용
- 신규 기능
- UX 개선
- 사용자나 운영자가 바로 느끼는 버그 수정
- 배포나 운영 대응에 필요한 메모

## 예시
- `2026-04-02.md`
