# Order Friends UX 개선 백로그 (2026-03-02)

## 목적
- 경쟁 비교 리포트를 실제 개발 작업 단위로 전환한다.
- 우선순위, 완료 기준, 측정 지표를 명확히 정의한다.

## P0 (0~2주)

### OF-UX-P0-01 주문 운영 실시간 신호 강화
- 범위: `apps/web/src/app/customer/orders/page.tsx`, `apps/web/src/providers/NotificationProvider.tsx`
- 작업:
  - 상단 요약 카드에 `신규/지연/미처리` 강조 상태 추가
  - 자동갱신 주기 옵션(빠름/기본/절전) 추가
  - 알림 리스트 정렬 규칙 개선(신규/지연 우선)
- 완료 기준:
  - 운영자가 주문 목록에서 1회 클릭 없이 신규/지연 주문을 식별 가능
  - 자동갱신 모드 전환이 UI에 즉시 반영

### OF-UX-P0-02 주문 상세 예외 액션 패널
- 범위: `apps/web/src/app/customer/orders/[orderId]/page.tsx` (또는 상태 액션 컴포넌트)
- 작업:
  - `품절`, `대체`, `취소사유` 입력 패널 UI 추가
  - 액션 실행 전 확인 모달 및 실패 복구 안내 추가
- 완료 기준:
  - 주문 상세 화면에서 예외 처리 액션을 2스텝 이내 수행 가능
  - 실패 시 재시도/되돌리기 동선 존재

### OF-UX-P0-03 핵심 문구 품질 게이트
- 범위: `apps/web/src/app/order/*`, `apps/web/src/app/customer/*`, `apps/web/src/components/ui/*`
- 작업:
  - 주문/결제/상태 라벨 전수 점검 체크리스트 추가
  - CI 전 단계에서 핵심 라벨 스냅샷 점검(테스트 또는 lint 규칙)
- 완료 기준:
  - 핵심 운영/고객 페이지에 깨진 한글 문자열 0건
  - 라벨 변경 시 자동 검사 경고 발생

## P1 (3~6주)

### OF-UX-P1-01 분석 카드 액션화
- 범위: `apps/web/src/app/customer/analytics/page.tsx`, `apps/web/src/app/customer/analytics/brand/page.tsx`
- 작업:
  - 차트/카드별 `바로 실행` 버튼 추가
  - 예: 품절 다발 상품 -> 상품 노출/재고 화면 딥링크
- 완료 기준:
  - 분석 화면에서 운영 화면으로 이동하는 클릭 수 1회
  - 주요 카드 3개 이상 액션 연결 완료

### OF-UX-P1-02 모바일 주문 처리 바
- 범위: `apps/web/src/app/customer/orders/page.tsx`, `apps/web/src/app/customer/orders/[orderId]/page.tsx`
- 작업:
  - 하단 고정 액션 바(접수/준비/완료/예외) 추가
  - 작은 화면에서 터치 타겟 최소 44px 확보
- 완료 기준:
  - 모바일 화면에서 상태 변경 2탭 이내 완료
  - 주요 액션 버튼 오탭률 감소(세션 리플레이 또는 QA 측정)

### OF-UX-P1-03 빈 상태/오류 상태 복구 UX
- 범위: 주문/상품/분석 주요 페이지 공통
- 작업:
  - 빈 상태에 `다음 행동` 버튼 추가
  - 오류 상태에 `재시도`, `이전 단계`, `문의` 동선 명시
- 완료 기준:
  - 빈 상태 화면에서 이탈 없이 다음 액션 수행 가능
  - 오류 후 재시도 성공률 지표 수집 가능

## P2 (7~12주)

### OF-UX-P2-01 채널 통합 운영 보드
- 범위: 신규 페이지(예: `/customer/operations`)
- 작업:
  - 지점/온라인샵/채널별 SLA, 지연, 취소, 품절 현황 통합
  - 상태별 필터 및 drill-down 지원
- 완료 기준:
  - 운영자가 단일 화면에서 전체 채널 상태를 확인 가능
  - 지연/취소 상위 지점 식별 시간이 단축됨

### OF-UX-P2-02 규칙 기반 운영 자동화
- 범위: 주문/상품/알림 정책 설정 화면
- 작업:
  - 조건 기반 자동 정책(예: 지연 급증 시 준비시간 자동 상향)
  - 정책 적용 이력/롤백 지원
- 완료 기준:
  - 정책 실행 이력 조회 가능
  - 운영자가 수동 개입 없이 반복 작업 일부 자동화

## 공통 KPI
- 주문 최초 응답 시간(평균/95p): 20% 이상 단축
- 주문 이슈 처리 리드타임: 30% 이상 단축
- 운영자 모바일 세션당 처리 건수: 15% 이상 증가
- CS 문의 중 주문 처리 혼선 키워드: 20% 이상 감소
